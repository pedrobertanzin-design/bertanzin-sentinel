# Bertanzin Sentinel

**One place. Every system. Always monitored.**

Open-source system monitoring platform built with PHP for centralized monitoring, integrity verification, infrastructure metrics, audit logs, and incident management.

## About

Bertanzin Sentinel is an open-source project designed to centralize the monitoring and management of multiple systems through a single platform.

The project aims to provide visibility into system availability, application integrity, resource usage, access activity, and incidents through a unified interface.
